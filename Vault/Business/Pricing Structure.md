## Autera Automation OS Framework (USD — Global Market)

> Source: "Autera" 3-tier automation OS model

| Tier | Price | Stack | Build Time | Margin |
|------|-------|-------|-----------|--------|
| Single System | $500/mo | n8n + Supabase + Claude API | ~3 hrs | 97% |
| Operations System | $2,000/mo | Claude Code + Supabase + n8n + Next.js + Netlify + Resend | ~2 weeks | 96% |
| Full System | $4,000/mo | Everything + Stripe + HubSpot + Cloudflare + Arcjet | 90 days | 95% |

### Single System ($500/mo)
One end-to-end automation built around a single workflow:
- Google review requests sent after every job
- Lead form → CRM entry → instant follow-up email
- Invoice sent automatically when a job is marked done
- Basic dashboard so client can see it working

### Operations System ($2,000/mo)
The business finally has a backend:
- Custom CRM built around how their business works
- Pipeline tracking from lead → close → delivery
- Automated follow-up sequences on every new deal
- AI handling inbound emails and routing them
- Basic reporting + client-facing status updates

### Full System ($4,000/mo)
Growth engine + operations. The whole thing:
- Conversion-optimised website
- Lead capture → CRM → 7-touch automated follow-up
- Full CRM: contacts, deals, pipelines
- AI document parsing
- Client portal — customers self-serve
- Invoicing, AR aging, automated payment reminders
- Reporting dashboards
