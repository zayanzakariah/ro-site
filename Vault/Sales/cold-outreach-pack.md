# Cold Outreach Pack — Niche Scripts

**Strategy:** Hook in first message → demo link in second → call CTA in third (48h later)

---

```

to send reminder? Even one per week costs you ₹4K+.

We've cut this to near-zero for 15+ clinics in [City] using WhatsApp
reminders. Chat when you're free? No pressure.

— Zayan
```

### Message 2 (48h later) — Demo
```
[Owner], wanted to show you exactly how this works.

Live demo: [demo-bot-link]
(just ask for appointment—shows what your patients see)

This is running for Dr. Mehta's clinic in Gurgaon. Takes 2 minutes.

Will follow up Thursday evening. Free then?
```

### Message 3 (72h later) — Call CTA
```
[Owner], guessing you're busy, but 15 mins could save you ₹10–15K/month.

Quick call Thursday at 10 AM?
[calendar-link]

No fluff—just show you the setup and answer questions.
```

## RESPONSE PATTERNS

| Response | Next Move |
|---|---|
| "Sounds interesting, send proposal" | Send 1-pager + demo link + say "let's hop on 10-min call to Q&A" |
| "Already have a website / bot" | "Cool. Is it bringing in leads? Because most aren't. Let's see how you compare." [Demo] |
| "Too expensive" | "What if it paid for itself in month 1? Let's talk numbers on a call." |
| "WhatsApp is enough" | "For now, yeah. But you're missing ₹X in lost leads monthly because follow-up's slow. Worth a look?" |
| "Talk to my partner" | "Perfect. Should I schedule a call with both?" |
| Ghosted | Re-engage in 7 days with 1-2 liner: "Checking in. Still managing [pain]?" |

---

## Notes
- **Timing:** Weekday 9–11 AM or 2–4 PM (IST)
- **Tone:** Professional but warm. Hindi/English mix if comfortable.
- **Demo link:** Pre-built bot showing exactly their pain point (clinic: no-show reminder; agent: lead follow-up, etc.)
- **Calendar link:** Calendly with clear time slots
