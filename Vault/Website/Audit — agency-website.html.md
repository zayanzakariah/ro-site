## What's Missing

### P0 — Critical

**1. Hero Headline Doesn't Signal "Operating System"**
Current: "MORE CLIENTS. POWERED BY AI."
Problem: Prospect thinks "website builder." Not "I'm buying an ops backend."

**2. No "Three Systems" Section**
Missing a visual breakdown of the automation tiers between Services and Pricing.

**3. Pricing Names Don't Signal Automation**
Current: Starter / Growth / Premium (website project framing)
Should be: Single System / Operations System / Full System (automation OS framing)

---

### P1 — High Impact

**4. No Interactive Lead Calculator**
Most persuasive element for Indian SMBs: "How much revenue are you leaving on the table?"

**5. No Deep Case Study**
"40+ bookings automated" exists but no full flow shown. Need: before/after with specific numbers.

---

### P2 — Supporting

**6. No FAQ section on automation**
Q: What's different about Tier 1 vs Tier 2? Can I start small? Do you set up HubSpot?

**7. No "What you'd pay separately" anchor**
Show: HubSpot ₹2k + n8n ₹500 + Supabase ₹100 + hosting ₹300 = ₹2,900/mo. We do all this for ₹12k/mo (bundled + built + supported).

## Recommended Hero Headlines (3 Options)

**Option A — OS Positioning:**
```
WEBSITES DON'T GROW CLINICS.
OPERATING SYSTEMS DO.

We build the platform that qualifies leads,
books appointments, and invoices—automatically.
```

**Option B — Scale Positioning:**
```
YOUR BUSINESS, AUTOMATED.

From a single workflow to a full enterprise system.
Website + CRM + Lead Capture + AI. All in one platform.
```

**Option C — Pain Positioning (Best for cold outreach):**
```
STOP LOSING LEADS TO SLOW FOLLOW-UPS.

We'll automate yours. Website + AI + CRM + invoicing.
Running 24/7. One platform. Indian pricing.
```

**Recommendation:** Option A for website. Option C for WhatsApp/cold outreach.

## Interactive Element Recommendation

**"Lead Multiplier Calculator"** — most persuasive for Indian SMB owners

Inputs: Industry / Current monthly leads / Current conversion rate / Avg deal value
Output: "You're leaving ₹X/month on the table. Autera closes that gap. ROI: 20×. Cost: ₹12k/mo."

Why it works: Shows THEIR numbers. Self-qualifying. They share it with their accountant.
